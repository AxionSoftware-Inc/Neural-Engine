# V0.104 Operator-Valued Matched Teacher Task

## Question

Does the operator-valued parameterization help on a task loss, rather than
only on a direct weight reconstruction oracle, when the target contains
reusable operator structure?

## Protocol

A known `384 -> 384` teacher was generated by the canonical `g=16,q=8`
operator-valued layer. Five students saw the same 8,192 training examples and
were evaluated on 2,048 fresh examples for 1,000 Adam steps on the RTX 3060:

- learned operator basis (`g=16,q=8`);
- fixed random basis with trainable coefficients;
- global dense low-rank rank 8 (6,144 trainable scalars);
- block-diagonal dense packets (6,144 trainable scalars);
- full dense matrix (147,456 trainable scalars).

Relative MSE is normalized by evaluation target energy. The task, data, steps,
and evaluation distribution are shared across all variants.

```powershell
python -u experiment_operator_task.py --device cuda --steps 1000 --output results/runs/operator_valued_task.json
```

## Results

| variant | trainable scalar DOF | eval relative MSE | training seconds |
|---|---:|---:|---:|
| learned operator basis | 6,656 | **1.42e-13** | 1.36 |
| fixed random basis | 4,608 | 0.9795 | 1.07 |
| global low-rank rank 8 | 6,144 | 0.9105 | 0.88 |
| block-diagonal dense | 6,144 | 0.9659 | 0.83 |
| full dense | 147,456 | 4.06e-13 | 0.72 |

The learned operator basis matches the full dense teacher to numerical
precision with 22.15x fewer stored scalar values. It also beats both
equal-DOF controls by a large margin on the structured target. The fixed
random basis fails, so the result depends on learning reusable operators.

## Decision

Gate 2 passes for a deliberately structured synthetic target. This is a
positive representation signal, not yet evidence of a general Neural Engine
accuracy gain. The direction remains isolated and should next be tested as a
single replacement layer in the existing synthetic composition model, with
the current router/register graph unchanged. Do not combine with MacroCells,
new routing, or factorized circuit changes yet.
